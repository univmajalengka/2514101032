# 🌊 Wisata Tanjung Benoa

Website **Wisata Tanjung Benoa** merupakan project website yang dibuat untuk memberikan informasi mengenai salah satu destinasi wisata terkenal di Bali, yaitu **Tanjung Benoa**.

Project ini dibuat sebagai bagian dari **tugas perkuliahan** sekaligus sebagai penerapan dasar pembuatan website menggunakan HTML dan CSS.

## 📌 Tentang Website

Website ini menyajikan informasi mengenai wisata Tanjung Benoa, mulai dari pengenalan destinasi, daya tarik wisata, aktivitas yang dapat dilakukan, hingga informasi lainnya yang dapat membantu pengunjung mengenal Tanjung Benoa.

## ✨ Fitur Website

Beberapa bagian yang tersedia pada website ini antara lain:

- **Home** — Halaman utama website.
- **About** — Informasi mengenai Tanjung Benoa.
- **Destination** — Menampilkan informasi destinasi atau tempat menarik.
- **Activity** — Informasi mengenai aktivitas wisata yang dapat dilakukan.
- **Gallery** — Menampilkan dokumentasi atau foto wisata Tanjung Benoa.
- **Video** — Menampilkan video yang berkaitan dengan Tanjung Benoa.


## 💻 Teknologi yang Digunakan

Project website ini dibuat menggunakan:

- **HTML5** — Untuk membuat struktur halaman website.
- **CSS3** — Untuk mengatur tampilan dan desain website.

## 🚀 Cara Menjalankan

1. Clone atau download repository ini.
2. Buka folder project.
3. Jalankan file `index.html` menggunakan browser.
4. Website Wisata Tanjung Benoa akan ditampilkan.

## 🎯 Tujuan Project

Project ini bertujuan untuk melatih kemampuan dalam membuat dan mendesain website serta mengimplementasikan materi HTML dan CSS yang telah dipelajari selama perkuliahan.
